# Vending machine sound samples

Original synthesized audio, generated by `scripts/generate-vending-audio.py`.
No external recordings, copyrighted melodies, or third-party sound libraries.
All files are mono 44.1 kHz, 16-bit PCM WAV.

Each 3-second sample uses the same timeline: button at 0.15s, dispensing at
0.70s, collection at 1.90s.

- `retro.wav`: quiet arcade button notes, motor, landing thunk, pickup chime.
- `warm.wav`: round sine notes, softer motor and lower landing sound.
- `mechanical.wav`: physical click, ratchet/motor, landing and hatch movement.

The app's default is the retro set, split into `../vending-press.wav` (0.24s),
`../vending-dispense.wav` (0.96s), and `../vending-pickup.wav` (0.38s).
Playback follows the application's global effects volume.

The generator refuses to replace existing files. To experiment safely, pass a
fresh `--output-root` directory.

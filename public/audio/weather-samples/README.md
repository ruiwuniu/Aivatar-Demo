# Park weather audio candidates

These auditioned files are now wired into the park weather runtime. The
`candidate` suffix is retained so the approved file paths stay stable.

## Rain layers

- `rain-layer-fine-candidate.ogg`: quiet fine-rain bed for sprinkle and light
  rain.
- `rain-layer-surface-candidate.ogg`: brighter grass and water impact texture
  for light through heavy rain.
- `rain-layer-downpour-candidate.ogg`: denser rain body for heavy rain and
  storms.

Source: **Rain (loopable)** by Ylmir on OpenGameArt.

- Page: https://opengameart.org/content/rain-loopable
- Source archive: `Rain OGG.zip`
- License: CC0 1.0 Universal
- Original files used: `4.ogg`, `3.ogg`, and `2.ogg`

The original recordings are loopable stereo Ogg Vorbis files. They are kept
unmodified for this audition.

## Thunder distance candidates

- `thunder-distant-candidate.wav`: low-pass filtered, quieter, with a long
  multi-tap tail.
- `thunder-medium-candidate.wav`: moderately filtered with a shorter rolling
  tail.
- `thunder-near-candidate.wav`: brighter and louder with only a short early
  reflection.

Source: **100 CC0 SFX #2** by rubberduck on OpenGameArt.

- Page: https://opengameart.org/content/100-cc0-sfx-2
- Source archive: `sfx_100_v2.zip`
- License: CC0 1.0 Universal
- Original file used: `sfx100v2_thunder_01.ogg`

All three candidates are derived from the same source recording so their
character remains consistent when randomly mixed. The derived WAV files use
48 kHz stereo 16-bit PCM.

# Aivatar 0.5.3

More reliable learned bubbles, a sharper fishing challenge, and new Macintosh colors.

## What's new

- **LLM bubble learning fixes.** Improve Codex Desktop's background learning calls and compatibility with newer Claude Code and OpenCode clients. Growth candidates prioritize LLM suggestions, persist with each save, and show actionable failure reasons instead of silently disappearing. Missing or unavailable providers still use the local fallback.
- **WorkBuddy learning.** WorkBuddy can generate learned bubbles through the official CodeBuddy CLI using sanitized task metadata. The CLI must be installed and signed in; an unavailable or incompatible client produces a visible diagnostic and local fallback. Alternative supported engines require explicit configuration.
- **Harder fishing QTE.** The hit zone is now only **8%–12% of the track**, down from 20%–32%. Random speed and direction remain, with three hits to land a catch and two misses to lose it. Catch probabilities and trophy uniqueness are unchanged.
- **Two Macintosh terminal skins.** Choose a forest-green shell with an orange CRT, or an orange shell with a deeper green CRT. Each costs 2600 Bits and shares the classic skin's animations, footprint and interaction points in both room and desktop modes.
- **Consistent inventory cards.** Restore default card dimensions and replace the six raw-fish, pond-weed, salad and four trophy thumbnails with twelve readable 16×16 pixel icons.

## 更新内容

- **修复 LLM 气泡学习。** 改善 Codex 桌面端的后台学习调用，兼容新版 Claude Code 和 OpenCode。成长面板优先展示 LLM 候选句，并随存档持久保存；学习失败时显示可操作的原因提示，服务不可用时保留本地回退。
- **WorkBuddy 气泡学习。** 使用脱敏任务元数据，通过官方 CodeBuddy CLI 生成候选句。需要安装并登录 CLI；缺失、不兼容或调用失败时给出明确提示并本地回退。其他受支持引擎须由用户显式配置。
- **钓鱼 QTE 判定收紧。** 判定区域从轨道的 20%～32% 缩窄为 **8%～12%**，保留随机速度和方向，以及三次命中成功、两次失误脱钩的规则。掉落概率及奖杯唯一性保持不变。
- **两款麦金塔终端皮肤。** 新增墨绿外壳配橙色荧光屏，以及橙色外壳配加深绿色荧光屏；每款 2600 Bits，房间与桌面共用经典款的动画、占地与互动点。
- **背包卡片与图标统一。** 卡片恢复默认尺寸；六种生鱼、水草、沙拉和四种奖杯改用十二款清晰的 16×16 简化像素图标。

LLM learning requires Node.js and an available, compatible CLI signed into the corresponding service. On supported macOS installations, Codex/OpenCode may use the CLI bundled with the desktop app. WorkBuddy uses the separately installed CodeBuddy CLI. If an OpenCode upgrade changes its plugin API, use Aivatar's **Enable/Repair** integration action and restart OpenCode to load the updated adapter.

LLM 学习需要 Node.js，以及可用、版本兼容且已登录相应服务的 CLI。受支持的 macOS 安装可使用 Codex/OpenCode 桌面端自带 CLI；WorkBuddy 使用另行安装的 CodeBuddy CLI。如果 OpenCode 升级改变了插件 API，请使用 Aivatar 集成面板中的**启用/修复**，并重启 OpenCode 加载更新后的适配器。

## Updating from 0.5.2 / 从 0.5.2 更新

The official 0.5.2 app can discover 0.5.3 after it is published as the latest stable release. It checks about eight seconds after startup, once per application process. If the app is already running, use **Settings → Check for updates**, or restart it. Download the update, then choose **Install and restart**. All open persistent rooms must save successfully before installation proceeds.

0.5.3 发布为最新正式版后，官方 0.5.2 安装版可以发现更新：启动约八秒后自动检查一次；已在运行的应用可使用**设置 → 检查更新**，或重启应用。下载后选择**安装并重启**，所有已打开的持久化窗口成功保存后才会安装。

## Install / 安装

- **macOS:** Universal DMG and updater archive for Apple Silicon and Intel.
- **Windows:** x64 NSIS EXE and MSI installers with their matching updater signatures.
- **macOS：** 适用于 Apple Silicon 和 Intel 的 Universal DMG 及更新归档。
- **Windows：** x64 NSIS EXE、MSI 安装包及匹配的更新签名。

Updater artifacts use the existing public key and signatures bound to version 0.5.3. These signatures are separate from operating-system code signing; Apple notarization and trusted macOS/Windows code-signing certificates are not configured. Windows native interaction still needs user testing.

更新包沿用现有公钥，并通过签名绑定 0.5.3 版本号。更新专用签名与系统代码签名不同；Apple 公证及受信任的 macOS/Windows 代码签名证书尚未配置。Windows 原生交互仍需用户实测。

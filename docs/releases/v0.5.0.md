# Aivatar 0.5.0

Your pixel companion can now leave its room and work beside you on the desktop.

## What's new

- **Desktop companion mode:** bring the character and its computer onto the desktop, independently drag them, and keep the character above the computer.
- **Live task behavior:** idle wandering and short bubbles give way to walking to the computer, thinking, typing, waiting, completion, or error feedback.
- **Return and remember:** right-click to return to the room; the next desktop visit restores the saved positions. Compact sprites and click-through empty space keep the desktop usable.
- **In-app updates:** automatic release checks, update notes and download progress, with user-controlled installation after every open persistent window has acknowledged saving.
- **A refreshed homepage:** new imagegen artwork and a single current-version highlights section.

## 更新内容

- **桌面伙伴模式：** 角色和电脑可以离开房间来到桌面，分别拖动摆放，角色位于电脑上层。
- **任务状态联动：** 空闲时散步、冒短句；任务开始后走到电脑前，显示思考、敲字、等待、完成或出错状态。
- **回房与位置记忆：** 右键角色回房，下次来到桌面时恢复上次位置；紧凑尺寸和透明区域点击穿透减少遮挡。
- **应用内更新：** 自动检查新版，提供说明及下载进度；用户决定安装时间，所有持久化窗口保存确认后才安装重启。
- **首页更新：** 使用 imagegen 绘制新头图，更新亮点仅保留 0.5.0。

## Install / 安装

- macOS: universal DMG for Apple Silicon and Intel.
- Windows: x64 NSIS EXE or MSI installer.
- Older versions, including earlier local 0.5.0 test packages, need one manual installation of this release to enable future in-app updates.
- 旧版本和此前的本地 0.5.0 测试包，需要手动安装本次正式版一次，之后才能在软件中获取后续更新。

Desktop movement is currently confined to one display's usable work area, with one active desktop companion at a time. Windows installers are built and checked in CI; native Windows desktop interaction still needs user testing. macOS desktop interaction has been tested with an isolated profile.

桌面活动目前限定在一个显示器的可用区域，同一时间支持一个桌面伙伴。Windows 安装包由 CI 构建和校验，原生桌面交互仍需用户实测；macOS 桌面交互已使用隔离存档测试。

Updater packages include cryptographic signatures. These are separate from operating-system code signing: Apple notarization and trusted macOS/Windows code-signing certificates are not configured. Checksum reports are included with the release.

更新包带有更新专用签名，发布附件包含校验报告；Apple 公证和受信任的 macOS/Windows 系统代码签名证书仍未配置。

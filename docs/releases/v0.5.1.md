# Aivatar 0.5.1

More room for your desktop companion, with a vending machine and a Macintosh-style terminal.

## What's new

- **Adjustable desktop activity area.** Right-click the desktop terminal to highlight and resize the companion's roaming area. Move or resize its bounds, then confirm to save the layout.
- **Desktop vending machine.** Place or pack it away from the terminal's right-click menu. Drag it independently while keeping it clear of the terminal. Your companion can buy and immediately enjoy cookies, cola, and coffee, with pickup animations and sound effects.
- **Three vending colors.** Right-click the vending machine to buy items or choose Original, Red, or Dark green. Left-click remains for dragging. The selected color is remembered when you return to the room or pack and place the machine again.
- **Macintosh terminal skin.** A new shop skin shared by the room and desktop, with screen, indicator, and typing animations that follow task states.
- **Stove interaction fix.** Frying fish now uses the selected stove's interaction point and cooking status instead of the coffee machine's brewing behavior.

## 更新内容

- **调整桌面活动区域。** 右键桌面终端可高亮并调整角色的活动范围，支持拖动区域及边缘缩放，确认后保存布局。
- **桌面自动售货机。** 通过终端右键菜单放置或收起，支持独立拖动并避免与终端重叠。角色可购买并立即使用曲奇、可乐和咖啡，配有取货动画与音效。
- **售货机三色皮肤。** 右键售货机可购买商品或选择原色、红色、墨绿色；左键保留拖动。回房间、收起再放置后仍记住配色。
- **麦金塔风格终端。** 商店新增房间与桌面共用的终端皮肤，屏幕、指示灯及敲字动画随任务状态变化。
- **炉灶互动修复。** 煎鱼现在使用所选炉灶的互动点和烹饪状态，不再映射到咖啡机或显示煮咖啡。

## Updating from 0.5.0 / 从 0.5.0 更新

The official 0.5.0 release with in-app updates can discover 0.5.1 after startup, or through **Settings → Check for updates**. Download the update, then choose **Install and restart** when ready. Open persistent rooms must save successfully before installation proceeds. Earlier preview packages without the updater need a manual installation.

带自动更新功能的 0.5.0 正式版可在启动后发现 0.5.1，也可在**设置 → 检查更新**中手动检查。下载后自行选择**安装并重启**；所有已打开的持久化窗口成功保存后才会安装。没有更新模块的早期测试包仍需手动安装。

## Install / 安装

- **macOS:** Universal DMG and update archive for Apple Silicon and Intel.
- **Windows:** x64 NSIS EXE and MSI installers.
- **macOS：** 适用于 Apple Silicon 和 Intel 的 Universal DMG 及更新归档。
- **Windows：** x64 NSIS EXE 和 MSI 安装包。

Updater artifacts carry signatures bound to version 0.5.1. These signatures are separate from operating-system code signing; Apple notarization and trusted macOS/Windows code-signing certificates are not configured. Windows native desktop interaction still needs user testing.

更新包使用绑定 0.5.1 版本号的更新专用签名。该签名与系统代码签名不同；Apple 公证及受信任的 macOS/Windows 代码签名证书尚未配置。Windows 原生桌面交互仍需用户实测。
